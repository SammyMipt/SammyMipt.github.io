Любое движение сводится к повороту

Теорема Эйлера: тело с неподвижной точкой переводится из любого положения в любое одним поворотом вокруг некоторой оси через эту точку.
  • Есть неподвижная точка — мгновенное вращение вокруг оси через неё
  • Нет неподвижной точки — поступательное движение плюс вращение вокруг мгновенной оси
